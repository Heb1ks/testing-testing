# PM Practice

Учебный тест по 188 вопросам из Project_Management_188_questions.docx. Порядок и номера сохранены, список разделён на четыре части по 47 вопросов. Все правильные ответы соответствуют новому документу, включая изменённый ответ в вопросе 23.

Для прежних вопросов сохранены неверные ответы из старой базы. Для 11 добавленных вопросов составлены три учебных неверных ответа; это не варианты из исходного нового документа. В каждой попытке показываются четыре ответа, включая правильный. Варианты ответов перемешиваются, вопросы идут по порядку.

Ответ проверяется сразу. Первый выбор сохраняется. Завершить тест можно в любой момент: процент считается по отвеченным вопросам, пропуски отмечаются отдельно. Доступны разбор и повторение ошибок. Прогресс новой базы хранится отдельно от прежней попытки из 177 вопросов.

Локальный просмотр: `python -m http.server 8080`. Публикация GitHub Pages: Deploy from a branch → main → / (root).

Вопросы, сценарии и все варианты ответов на английском. Русские сценарии из нового документа переведены с сохранением условий и числовых данных. Интерфейс на русском.
