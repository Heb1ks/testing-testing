# PM Practice

Учебный тест: все 235 вопросов из 1-5.docx. Правильные ответы соответствуют Project_Management_Answer_Keys__Variants_1-5_.pdf. Вопросы, сценарии и варианты ответов на английском, интерфейс на русском.

Варианты 1–5 содержат 50 / 39 / 50 / 50 / 46 вопросов. В варианте 2 отсутствуют № 12 и № 37–46, в варианте 5 — № 1–4. Пропуски подтверждены и документом, и PDF; отсутствующие вопросы не восстановлены догадками. Номера и порядок сохранены, повторяющиеся между вариантами вопросы включены.

В данных сохранены все пять исходных ответов. На экране показываются правильный и три случайных неверных, порядок ответов перемешивается. Ключ из PDF применяется к исходной букве ответа до перемешивания. Вопросы идут по порядку варианта и номера.

Правильный ответ показывается сразу, первый выбор сохраняется. Тест можно завершить в любой момент: процент считается по отвеченным вопросам, пропуски выводятся отдельно. Доступны разбор и повторение ошибок. Прогресс этой базы хранится отдельно от прежней версии.

Локальный просмотр: `python -m http.server 8080`. GitHub Pages: Deploy from a branch → main → / (root).
