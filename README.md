# PM Practice

Статический сайт для подготовки к экзамену по управлению проектами. Все 177 вопросов из предоставленного документа: 50 / 40 / 50 / 37 по четырём наборам. Номер второго набора в исходнике предположительный. Отсутствующие в документе вопросы не добавлены.

В questions.json сохранены все пять исходных ответов и ключ. В каждой попытке показываются правильный ответ и три случайных неверных. Вопросы и ответы перемешиваются. Доступны тест по всей базе, отдельные наборы, сохранение текущей попытки на устройстве, результат, разбор и повторение ошибок. Правильный ответ показывается сразу после выбора; первый ответ сохраняется для итогового результата и не меняется. Ключи ответов соответствуют документу; это учебный тренажёр, ключи доступны в исходном коде.

Для локального запуска: `python -m http.server 8080`, затем открыть http://localhost:8080. Сайт не требует сборки или зависимостей. Шрифт Google Fonts необязателен: без него используется системный шрифт.

Публикация: GitHub Pages → Source: GitHub Actions. Workflow в `.github/workflows/pages.yml` публикует сайт при изменении main.
